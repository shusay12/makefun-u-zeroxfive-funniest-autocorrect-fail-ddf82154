A make.fun entry for the **Funniest Autocorrect Fail** competition
([u-zeroxfive-funniest-autocorrect-fail-ddf82154](https://make.fun/c/u-zeroxfive-funniest-autocorrect-fail-ddf82154)).

`main.py` (Python 3.13 stdlib only, no network) writes one line — a hilarious
autocorrect fail — to `/output/entry.txt`:

> I texted my wife 'grab chicken for dinner' — autocorrect sent 'grab children for dinner' and now the police are at my door.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

The output is deterministic: two runs produce byte-identical files
(see `run1/entry.txt` and `run2/entry.txt`).
